# 🚀 About the Project :-

### ButtonAdda is an open-source React component library containing 49+ animated, interactive and customizable button components.

Instead of creating animations, hover effects and interactions from scratch every time, **ButtonAdda** allows developers to directly import expressive button components into their React applications.

ButtonAdda is built for developers who want to add personality, interaction and creative motion to their interfaces without repeatedly building complex button effects from scratch.

# 📦 Installation :-

Install ButtonAdda using npm:

```bash
npm install button-adda
```

Or using Yarn:

```bash
yarn add button-adda
```

Or using pnpm:

```bash
pnpm add button-adda
```

# 🚀 Quick Start :-

Import any ButtonAdda component directly into your React application:

```jsx
import { AuroraButton } from "button-adda";

function App() {
  return (
    <div>
      <AuroraButton>
        Click Me
      </AuroraButton>
    </div>
  );
}

export default App;
```

That's it! 🎉

---

# 🧩 Import Components :-

You can import individual components:

```jsx
import { AuroraButton } from "button-adda";
```

You can also import multiple components together:

```jsx
import {
  AuroraButton,
  BlackHoleButton,
  CableSendButton,
  ColorBurstButton,
  CyberButton,
  NeonButton,
} from "button-adda";
```

Then use them normally inside your React application:

# 🛠️ Customization :-

Many ButtonAdda components support customizable props.

Depending on the component, you can customize properties such as:

- 🎨 Color
- 📝 Text Color
- 📏 Width
- 📐 Height
- 🔘 Border Radius
- ✨ Animation Intensity
- ⚡ Animation Speed
- 🎯 Interaction Behavior
- 🚫 Disabled State

Example:

```jsx
import { AuroraButton } from "button-adda";

function App() {
  return (
    <AuroraButton
      color="#8b5cf6"
      textColor="#ffffff"
      width={180}
      height={52}
      radius={14}
      intensity={1}
    >
      Custom Button
    </AuroraButton>
  );
}

export default App;
```

> ⚠️ Available props may vary depending on the individual component. Check the ButtonAdda library site for component-specific props and detailed documentation.
